=== Demo 3: Asymmetric encryption - textbook RSA vs RSA-OAEP ===
  textbook RSA is deterministic: same message twice -> identical ciphertext = True
  textbook RSA is malleable: multiply ciphertext by 2^e -> decrypts to 2*m = True (attacker changed the value without the key)
  OAEP is randomized: two encryptions differ = True; both decrypt correctly = True
  OAEP rejects a modified ciphertext with a single generic 'decryption error'
  size limit: RSA-2048 + OAEP-SHA-256 carries at most 190 bytes -> HVMC uses hybrid encryption
  interop: OpenSSL decrypts from-scratch OAEP = True; from-scratch decrypts OpenSSL OAEP = True
