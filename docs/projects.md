## Healthcare IAM Operations Home Lab
![Healthcare IAM Project]({{ '/assets/img/project-placeholder.svg' | relative_url }})

A comprehensive 12-week intensive project focused on designing, implementing, and managing a complete Identity and Access Management (IAM) environment for a simulated healthcare organization. This project serves as my **Cybersecurity Capstone**, demonstrating my ability to secure sensitive patient data and critical systems.

- **Identity Lifecycle Management:** Implemented Joiner-Mover-Leaver (JML) processes to ensure secure and efficient account provisioning and deprovisioning.
- **Directory Services:** Configured and managed **Active Directory** and **Microsoft Entra ID**, bridging on-premises and cloud identity management.
- **Access Control:** Designed and maintained **Role-Based Access Control (RBAC)** structures, ensuring the principle of least privilege.
- **Security Operations:** Implemented Multi-Factor Authentication (MFA), Privileged Access Management (PAM), and conducted periodic access reviews to ensure security compliance.
- **Automation:** Developed **PowerShell** scripts to automate routine identity administration tasks and improve operational efficiency.
- **Documentation:** Authored detailed IAM design documentation and security analysis reports focusing on healthcare-specific security requirements.

## Smart Deal Alert (Python Price Tracker)
![Smart Deal Alert]({{ '/assets/img/project-placeholder.svg' | relative_url }})

A multi-user Python application designed to monitor product prices across various online platforms and send automated alerts when user-defined targets are met.

- **Backend Development:** Built using **Python** with a structured algorithm for price comparison and monitoring.
- **Authentication:** Implemented a secure user registration and login system.
- **Data Persistence:** Utilized **JSON** for storing user preferences, monitored products, and historical price data.
- **Core Functionality:** Users can track multiple products, set target prices, and receive "Deal Alerts" when the current price matches or falls below their target.
