# Semester 1 — Python Foundations

Beginner Python work built around one project idea: **Smart Deal Alert**, a price-tracker that warns a user when a product
they watch drops below their target price. Each folder is a step in how the program grew.

| Folder / file | What it shows |
|---|---|
| [price_tracker/main.py](./price_tracker/main.py) | First version: welcome message, simple login loop, price check |
| [python_1/Smart_Deal_Alert_Algorithm.py](./python_1/Smart_Deal_Alert_Algorithm.py) | The algorithm written out step by step |
| [python_1/Simple_Smart_Deal/](./python_1/Simple_Smart_Deal/) | Simple version |
| [python_1/Smart_Deal_Alert_With_JSON/](./python_1/Smart_Deal_Alert_With_JSON/) | Tracked products saved in a JSON file |
| [python_1/smart_deal/](./python_1/smart_deal/) | Watch list read from a CSV file |
| [python_1/Smart_Deal_Alert_Multiuser/](./python_1/Smart_Deal_Alert_Multiuser/) | Several users, each with their own data |
| [python_1/Smart_Deal_Alert_Final/](./python_1/Smart_Deal_Alert_Final/) | Final version built from the pseudocode, plus a Git & GitHub beginners guide |
| [python_1/functions.py](./python_1/functions.py), [home_destiny_guru.py](./python_1/home_destiny_guru.py) | Practice exercises (functions, loops, input) |

**Concepts:** variables, loops, conditions, functions, file handling (JSON, CSV), simple data structures.
The usernames and passwords in the practice scripts are classroom examples, not real accounts.
