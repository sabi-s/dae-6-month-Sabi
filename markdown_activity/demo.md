# Markdown Quick-Start Guide

Markdown is a **lightweight markup language** for formatting *plain text*.

## What Markdown Can Do

Markdown can help me:

  - organise a README
  - format project documentation
  - write content for GitHub Pages
 
  ## Steps I Followed

  1. Created a `.md` file
  2. Added Markdown syntax
  3. Opened the preview
  4. Tested and reviewed the file
