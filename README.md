# Sabitha S Karanavar — Cybersecurity & IAM Portfolio

**IAM Security Analyst & Web Developer** — moving from full-stack web development into Identity and Access Management.
This repository holds my work from the 6-month programme: course rubrics, weekly status updates and my capstone project.

## ⭐ Capstone project: AccessGuard Health

A simulated Identity and Access Management programme for **Horizon Valley Medical Center (HVMC)**, a fictional hospital:
Samba Active Directory, Microsoft Entra ID, role-based access, joiner / mover / leaver automation, access reviews,
MFA support, non-human identities and secrets management with Azure Key Vault.
